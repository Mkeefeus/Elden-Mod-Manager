# Launching the Game

There are two ways to start Elden Ring from Elden Mod Manager:

## Launch Modded

Loads the game through [me3](https://github.com/garyttiereny/me3) with whatever mods are **enabled** in your **active profile**, in that profile's load order, using that profile's launch settings.

Trigger it with:
- **Launch Game** on the [Mods page](managing-mods.md)
- **Play (Current Profile: ...)** on the Home page

## Play Vanilla

Launches unmodded Elden Ring directly through Steam — no mods, no me3. Trigger it with **Play Vanilla** on the Home page.

## Per-Profile Launch Settings

These live under **Show Advanced** on the Mods page and apply only to the active profile — see [Profiles](profiles.md#profile-specific-settings) for the full list (custom save file, Start Online, Disable Arxan, Skip Memory Patch, and the Linux-only [Proton verb override](linux.md#the-proton-launch-verb)).

## Global Launcher Settings

These live on the [Settings page](settings-and-backup.md#launcher-settings) and apply no matter which profile is active — see there for the full list (Disable Boot Boost, Show Intro Logos, Skip Steam Init).
